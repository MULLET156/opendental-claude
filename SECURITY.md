# Security policy

This project handles access to dental patient records. Please report security problems **privately**:

- Use GitHub's **"Report a vulnerability"** button on the Security tab of this repository (private advisory).
- Don't open a public issue for anything that could expose patient data or keys.
- Never include real patient data, Open Dental keys or gateway app keys in a report. Use Open Dental's public test database to reproduce.

You'll get an acknowledgement within a week. Fixes are released as a new version with a note in the changelog.

Supported versions: the latest release.
